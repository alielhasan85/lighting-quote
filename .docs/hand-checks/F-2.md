# F-2 — check by hand

**Run:** `npm run dev` · two accounts on the Neon dev branch:

- **Account A:** signed in, in its own private window, with its workspace at `/w/<id>`.
- **Account B:** a Google account, in a second private window. Delete B's `Membership` row first, so B is back on
  `/welcome`.

1. **`/welcome` has a way out and survives a failed submit.** As B, open `/welcome`.
   - Click "Sign in with another account" below the form → Auth.js's sign-out page. Press the browser's Back button
     without confirming.
   - DevTools → Network → Offline. Type a name and click "Create workspace" → "Couldn't create the workspace. Try
     again.", and the name stays in the field. Turn Offline off.
   - Open `/api/auth/signout` in a second tab of this window and confirm. Back in the first tab, click "Create
     workspace" → you land on `/login?callbackUrl=%2Fwelcome`.

2. **The phone sidebar closes after a tap.** As A, on `/w/<id>`.
   - DevTools → device toolbar, at a phone width. Open the sidebar with the header's button and tap Home → the sidebar
     closes.

3. **The production build still passes.** Stop the dev server first. CI doesn't run a build.
   - Run `npm run build` → it finishes with no error.
